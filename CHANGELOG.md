# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-23

### Added

- `init` interactive profile wizard (gender, age, party, education, degree, major, grassroots, English, household, fresh status, certificates, veteran/disability/minority/athlete).
- `download` for official announcements, outlines, policies, FAQ, attachments and position table.
- `build` with colored official sheets, eligible positions, regional sheets and explanation.
- `fetch` for applicant counts from a logged-in Chrome session.
- `snapshot` for daily counts, with “change vs previous snapshot”.
- `report` with totals, ranges, top lists, department and region summaries.
- `doctor`, `all`, `guide` and an interactive menu.
- Docs for quick start, other users, document download, data/Excel layout, fetching, FAQ and project structure.
