# 2027国考岗位工具 · 使用说明

> 把一个一次性的筛选/统计流程，封装成随时可调用的脚本。
> 入口：`gk2027.py`；双击启动：`run.command`；配置：`gk2027_config.json`。

---

## 一、这是什么

这个工具把整个项目串成 8 个可重复调用的功能，**别人拿到后改自己的条件即可用**：

1. **init**：交互式设置本人条件（性别/年龄/政治面貌/学历/学位/专业/基层年限/英语/户籍/应届身份/证书等），写入 `gk2027_config.json`。
2. **download**：从专题网站下载招考公告/大纲、政策法规、常见问题、相关附件和岗位表。
3. **build**：读官方岗位表，按本人条件筛出绿色/黄色岗位，生成带颜色标记、`符合条件岗位`、地区表和`筛选说明`的 Excel。
4. **fetch**：从已登录的 Chrome 职位查询页，抓取全部符合条件岗位的报名人数，保存为 JSON。
5. **snapshot**：把某天的 counts 合并进 Excel，与上一天并列，自动算“较昨日增加”。
6. **report**：生成独立的报名人数统计表（统计总表 + 汇总 + 说明）。
7. **doctor**：检查依赖、文件、Chrome 登录/页面脚本是否正常。
8. **all**：一键抓取→合并→统计；另有 **guide** 和交互菜单。

```

```

```bash
cd /Users/guidchen/Documents/DeepSeek-Harness-Projects/dsh-26gongkao
```

## 四、各个功能

### 0. init —— 设置本人条件

```bash
./run.command init
./run.command init --from-json my_profile.json
```

交互式填写：性别、年龄、政治面貌、学历、学位、专业代码/名称/关键词、基层年限、工作年限、服务基层项目、CET4/CET6、户籍省/市/县、应届身份、证书、退役军人/残疾人/少数民族/运动员等。

保存到 `gk2027_config.json`；之后 `build` 就按这套条件筛选。

> 不会影响已有的 Excel；只是改配置。建议第一次使用先跑 init。

### 0. download —— 下载官方资料

```bash
./run.command download
./run.command download --skip-pdf
./run.command download --only position --out /tmp/test
```

下载到 `2027国考资料/`：

- `01_招考公告与考试大纲/`：公告、报考指南、公共科目/专业科目/非通用语/公安大纲（HTML + PDF）；
- `02_政策法规/`：公务员法、录用规定、体检标准、考察办法等；
- `03_常见问题/`：实名认证等官方问答；
- `04_相关下载/`：招考简章 zip、电子社保卡指南、报名表/推荐表、证监会大纲、最新通知附件；
- `05_岗位表/`：从 zip 解压出的官方 `.xls`。

`--only` 可选 `all` / `position` / `articles` / `resources`；`--skip-pdf` 只存 HTML。网站新发布的“报名人数较少职位”等通知也会自动收录。

### 1. doctor —— 环境检查

```bash
./run.command doctor
```

检查：

- `xlrd / xlwt / xlutils` 是否安装；
- 官方岗位表、筛选工作簿、统计表是否存在；
- Chrome 是否运行、是否打开了 `bm.scs.gov.cn` 页面；
- 页面脚本能否执行（`JS_OK 2`）；
- 当前配置的本人条件。

环境正常时最后会显示“可以开始”。

### 2. build —— 生成筛选表

```bash
./run.command build
./run.command build --out /tmp/test.xls --force
./run.command build --no-regions
```

| 参数 | 说明 |
|---|---|
| `--official` | 官方岗位表 .xls 路径，默认取配置 |
| `--out` | 输出工作簿，默认 `2027国考资料/06_个人筛选/...按本人条件筛选.xls` |
| `--no-regions` | 不生成陕西/甘肃/西安地区表 |
| `--force` | 覆盖已存在文件 |

输出：原 4 个官方工作表（符合行标绿/黄）+ `符合条件岗位`（绿前黄后）+ `陕西省岗位` / `甘肃省岗位` / `西安市岗位` / `西安市全部岗位（参考）` + `筛选说明`。

> 原 4 张表的数值、列宽、行高、合并单元格不改；只加颜色和新表。

### 3. fetch —— 抓取报名人数

```bash
./run.command fetch --label 10-23
./run.command fetch --label 10-23 --workers 3 --retries 2 --out data/counts/xxx.json
```

**抓取前必须准备：**

1. Chrome 打开 <https://bm.scs.gov.cn/kl2027> 并完成登录；
2. 进入 **个人中心 → 职位查询 → 按代码选择职位**，保持页面打开；
3. Chrome 菜单：**显示 → 开发者 → 勾选“允许 Apple 事件中的 JavaScript”**；
4. 运行 `fetch`，按提示确认。

抓取逻辑：

- 自动从工作簿读取 1,034 个符合条件岗位；
- 分块注入页面，3 路并发请求职位详情接口；
- 失败自动重试 2 次；
- 结果写入 `data/counts/counts_<日期>.json`；
- 完成后清理页面临时元素。

如果登录过期，接口返回 401，工具会提示重新登录，不会写入坏数据。

### 4. snapshot —— 合并到 Excel

```bash
./run.command snapshot --label 10-23 --counts data/counts/counts_2026-10-23.json
```

| 参数 | 说明 |
|---|---|
| `--workbook` | 筛选工作簿，默认取配置 |
| `--counts` | fetch 生成的 JSON |
| `--label` | 快照标签，如 `10-23` |
| `--force` | 允许重复标签（不建议） |

效果：

- 若工作簿还没有快照：追加 `报名人数(标签)`、`报录比(标签)`、`更新时间(标签)`；
- 若已有上一个快照：再追加 `报名人数(标签)`、`报录比(标签)`、`较昨日增加(标签)`、`更新时间(标签)`；
- 同步写入 `符合条件岗位`、`陕西省岗位`、`甘肃省岗位`、`西安市岗位`；
- 在 `筛选说明` 末尾追加本次统计。

### 5. report —— 生成统计表

```bash
./run.command report
./run.command report --labels 10-22,10-23 --out /tmp/stats.xls --force
```

读取工作簿里最后 1—2 个快照，生成：

- `统计总表`：按最新报名人数降序，含两天报名/报录比/增加/更新时间/匹配等级；
- `汇总`：总体、按匹配等级、区间分布、前 20、增幅前 15、按部门、按地区；
- `说明`：数据来源、口径、排序、动态提示。

### 6. all —— 一键全流程

```bash
./run.command all --label 10-24
./run.command all --label 10-24 --skip-fetch --counts data/counts/counts_2026-10-24.json
```

依次执行：抓取 → 合并 → 生成统计表。

- `--skip-fetch`：已有 counts 时跳过抓取；
- 抓取失败会询问是否跳过，不会静默写坏数据。

### 7. guide / 菜单

```bash
./run.command guide
./run.command          # 交互菜单
```

## 六、数据与命名

| 文件 | 说明 |
|---|---|
| `data/counts/counts_YYYY-MM-DD.json` | 每次抓取的原始记录（职位代码/部门/报名人数/更新时间） |
| `报名人数(10-22)` | 10-22 快照 |
| `报录比(10-22)` | 报名人数 ÷ 招考人数 |
| `较昨日增加(10-23)` | 与上一快照的差值 |
| `匹配等级` | 绿色=明确符合；黄色=需电话确认 |

## 七、常见问题

**1. 接口返回 401 / 登录失效**

重新登录专题网站，打开“个人中心 → 职位查询 → 按代码选择职位”，保持页面打开后重试。

**2. 找不到页面 / `__NOT_FOUND__`**

工具只认 Chrome 里 URL 含 `person_position.html` 的标签页；请先打开该页面。

**3. Chrome 禁止 AppleScript 执行 JS**

菜单栏：**显示 → 开发者 → 勾选“允许 Apple 事件中的 JavaScript”**。只有勾选后 `fetch` 才能工作。

**4. 依赖缺失**

```bash
./setup.sh
```

或手动：

```bash
python3 -m venv .venv
.venv/bin/pip install xlrd xlwt xlutils
```

**5. Excel 文件被占用**

先关闭 WPS/Excel 中打开的目标文件，再运行 `snapshot` / `report`。

**6. 抓取很慢或部分失败**

默认 3 路并发；报名最后一天系统较慢。可降低并发：`--workers 2`，或重试 `--retries 3`。失败记录会保留 `err` 字段，可重跑 `fetch` 覆盖。

## 八、注意

- 报名人数会随报名进程变化，最终以系统实时数据为准；
- 绿色/黄色是辅助筛选，不替代官方资格审查；黄色岗位请拨打职位表内咨询电话确认专业、学位、英语、体能等；
- 工具只读取职位详情接口，不会修改报名信息；
- 生成的 Excel 原 4 个官方工作表不改，新增表/列均可追溯；
- 建议保留 `data/counts/` 下的原始 JSON，便于复核和重做统计。
