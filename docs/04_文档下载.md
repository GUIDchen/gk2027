# 文档下载

## 一、命令

```bash
./run.command download                 # 全部：文章 + 附件 + 岗位表
./run.command download --skip-pdf      # 只存 HTML，不生成 PDF
./run.command download --only position # 只下附件/岗位表
./run.command download --only articles # 只下文章（HTML/PDF）
./run.command download --force         # 覆盖已存在
```

## 二、下载到哪里

| 目录 | 内容 |
|---|---|
| `2027国考资料/01_招考公告与考试大纲/` | 公告、报名即将开始、报考指南、公共科目大纲、证监会/金融监管/非通用语/公安大纲，以及网站新发布的“报名人数较少职位”等通知（HTML + PDF） |
| `2027国考资料/02_政策法规/` | 公务员法、录用规定、面试组织管理办法、体检标准、考察办法、违规违纪处理办法等 10 份 |
| `2027国考资料/03_常见问题/` | 实名实人认证等 5 份官方问答 |
| `2027国考资料/04_相关下载/` | 招考简章 zip、电子社保卡指南、报名推荐表、报名登记表、证监会 4 份大纲、最新通知附件 |
| `2027国考资料/05_岗位表/` | 从 zip 解压出的官方 `.xls`（9.2MB） |

## 三、内容规模（2026-10-23 实测）

- 招考公告/大纲：9 篇（含新通知）；
- 政策法规：10 篇；
- 常见问题：5 篇；
- 合计 24 篇 HTML；
- 附件：4 个（zip/pdf/doc/docx）+ 证监会 4 份 `.doc` + 新通知 zip；
- 岗位表：1 个 `.xls`。

## 四、下载原理

1. 读取专题网站文章分组接口：`/api/article/{hb01Id}/{groupId}`；
2. 逐篇读取 `/api/article/{articleId}`，把正文图片内嵌为 base64；
3. 生成 HTML；用 Chrome headless 打印 PDF（`--skip-pdf` 可跳过）；
4. 读取 `/api/res/{hb01Id}/1110` 下载相关附件；
5. 从招考简章 zip 中解压第一个 `.xls` 到 `05_岗位表/`。

## 五、常见问题

- **下载很慢/失败**：政府网站偶尔限速，重跑即可；已下载的文件默认跳过。
- **PDF 没生成**：需要本机有 Google Chrome；没有就加 `--skip-pdf` 只留 HTML。
- **新通知没出现**：加 `--force` 重跑；工具会自动读取最新文章列表。
- **年份变化**：改 `gk2027_config.json` 的 `hb01_id` 和 `gk2027_lib/downloader.py` 的 `GROUPS`。

> 下载的是官方公开资料；个人报名信息、报名人数等不在这个命令范围内。
