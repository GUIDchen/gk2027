## 二、前 27 列（官方原格式）

部门代码、部门名称、用人司局、机构性质、招考职位、职位属性、职位分布、职位简介、职位代码、机构层级、考试类别、招考人数、专业、学历、学位、政治面貌、基层工作最低年限、服务基层项目工作经历、是否在面试阶段组织专业能力测试、面试人员比例、工作地点、落户地点、备注、部门网站、咨询电话1、咨询电话2、咨询电话3。

第 1 行是官方说明，第 2 行是表头，数据从第 3 行开始。

## 三、报名人数快照列

当前工作簿有 10-22、10-23 两天的快照：

| 列 | 说明 |
|---|---|
| 报名人数(10-22) | 10-22 报名总数 |
| 报录比(10-22) | 报名人数 ÷ 招考人数 |
| 更新时间(10-22) | 系统数据更新时间 |
| 报名人数(10-23) | 10-23 报名总数 |
| 报录比(10-23) | 同上 |
| 较昨日增加(10-23) | 10-23 − 10-22 |
| 更新时间(10-23) | 系统数据更新时间 |

新增快照时，`snapshot` 会自动在最后一列右侧追加同样的一组列；上一快照自动作为“较昨日”的基准。

## 五、颜色

- 绿色：明确符合，建议优先；
- 黄色：基本符合，但需电话确认（0835 学术学位、计算机/电子信息大类、学位学士、英语熟练、体能测评等）；
- 统计表中报名人数 ≥1000 红色、500—999 橙色、<100 绿色。

## 六、counts JSON

`data/counts/counts_YYYY-MM-DD.json`：

```json
[
  {
    "code": "300110000001",
    "dept": "130000",
    "name": "某省税务局",
    "bureau": "某市税务局",
    "title": "一级行政执法员",
    "num": "2",
    "book": 100,
    "up": 1792735504000,
    "rawbook": 100,
    "rawfirst": 0
  }
]
```

- `book`：报名人数（系统 `num`）；
- `up`：系统更新时间（毫秒）；
- `rawbook/rawfirst`：系统原始字段，便于追溯。

> 报名人数是报名总数；详情接口未返回“待审查/审查通过”分项。
