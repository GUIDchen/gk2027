# 常见问题

### 1. 为什么我 `build` 出来的数量和示例不同？

因为 `gk2027_config.json` 里的本人条件不同。`init` 改条件后，`build` 会按新条件重新计算。

### 2. 我改完 `init`，直接 `build` 还是旧结果？

- 命令行：每个子命令是独立进程，会重新读配置，正常；
- 交互菜单：`init` 后工具会自动热重载 matcher/build 模块，正常。
- 如果仍不对，退出重进。

### 3. 提示 Excel 文件被占用

关闭 WPS/Excel 中打开的目标文件，再运行 `snapshot` / `report`。

### 4. `fetch` 提示 `HTTP 401`

登录过期。重新登录专题网站，打开“个人中心 → 职位查询 → 按代码选择职位”，保持页面打开后重试。

### 5. `fetch` 提示找不到页面

工具只认 Chrome 里 URL 含 `person_position.html` 的标签页；请先打开该页面。

### 6. 提示“通过 AppleScript 执行 JavaScript 的功能已关闭”

Chrome 菜单栏：**显示 → 开发者 → 勾选“允许 Apple 事件中的 JavaScript”**。

### 7. 下载的文档没有 PDF

需要本机有 Google Chrome。没有就加 `--skip-pdf` 只留 HTML；或安装 Chrome 后重跑。

### 8. `download` 会重复下载吗？

默认会跳过已存在文件；要覆盖加 `--force`。

### 9. `snapshot` 提示标签已存在

同一天重复合并会被拒绝，避免出现两套同名列。确实要加就 `--force`，但不建议。

### 10. `report` 没有数据

先确认工作簿里有 `报名人数(标签)` 列（先跑 `snapshot`），并且 `符合条件岗位` 有数据。

### 11. `.venv` 不存在/依赖缺失

```bash
./setup.sh
```

或让 `run.command` 自动安装。

### 12. 报名人数和官方页面显示不一致

- 工具抓的是职位详情接口的报名总数；官方页面可能显示“待审查/审查通过”分项；
- 抓取时间不同，数字会变化；以系统实时为准。

### 13. 能把数据提交到 git 吗？

`2027国考资料/`、`data/`、`gk2027_config.json`、`考生基本信息.png` 已默认被 `.gitignore` 排除，避免个人信息和大文件进仓库。

### 14. 换年份怎么办？

改 `gk2027_config.json` 的 `hb01_id`，以及 `gk2027_lib/downloader.py` 里的 `GROUPS` 栏目 ID；并准备对应年份的岗位表。
