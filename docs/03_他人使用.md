# 他人使用（换成自己的条件）

> 工具默认配置是本项目作者的条件。别人使用时，**只需要跑一次 `init`**，不需要改代码。

## 一、最短流程

```bash
cd dsh-26gongkao
./setup.sh              # 首次安装依赖
./run.command init      # 填自己的条件
./run.command download  # 下载官方资料/岗位表
./run.command build     # 生成自己的筛选表
```

之后按需抓取报名人数（需要自己的 Chrome 登录）：

```bash
./run.command fetch --label 10-23
./run.command snapshot --label 10-23 --counts data/counts/counts_2026-10-23.json
./run.command report
```

## 四、改地区/路径/年份

### 地区表

`gk2027_config.json` 的 `regions`：

```json
"regions": ["陕西", "甘肃", "西安"]
```

改成自己关注的省/市即可，例如 `["河南", "郑州"]`。`build` 会按关键字生成 `河南省岗位`、`郑州市岗位` 等。

### 路径

同一文件里的 `official_xls`、`workbook`、`stats_xls`、`counts_dir` 可改。

### 年份/站点

- `hb01_id`：2027 国考的专题 ID。
- `gk2027_lib/downloader.py` 里的 `GROUPS` 栏目 ID 也是 2027 的。换年份时需要同步改。

## 五、恢复默认/重置

```bash
# 备份当前配置
cp gk2027_config.json gk2027_config.personal.json

# 用示例配置重新开始
cp gk2027_config.example.json gk2027_config.json
./run.command init
```

## 六、注意

- `init` 只改配置，不会动已有 Excel。
- 换人使用时，建议把 `2027国考资料/06_个人筛选/` 和 `data/counts/` 清空，避免混用上一个人的结果。
- 抓取报名人数需要使用者**自己的** Chrome 登录，工具不共享账号。
