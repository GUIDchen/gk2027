# 快速开始

## 1. 环境

- macOS（抓取报名人数需要 Chrome + AppleScript；筛选/下载可在 macOS 上跑）
- Python 3.9+
- Google Chrome

## 2. 安装

```bash
cd /Users/guidchen/Documents/DeepSeek-Harness-Projects/dsh-26gongkao
./setup.sh
```

`setup.sh` 会创建 `.venv` 并安装 `xlrd / xlwt / xlutils`。如果跳过，直接双击 `run.command` 也会自动安装。

## 3. 第一次使用

```bash
# 1) 按自己的条件填写
./run.command init

# 2) 下载公告/大纲/政策/问答/附件/岗位表
./run.command download

# 3) 生成筛选工作簿
./run.command build

# 4) 抓取报名人数（需先登录 Chrome）
#    Chrome 打开 https://bm.scs.gov.cn/kl2027
#    个人中心 → 职位查询 → 按代码选择职位，保持页面打开
#    菜单：显示 → 开发者 → 勾选“允许 Apple 事件中的 JavaScript”
./run.command fetch --label 10-22

# 5) 合并 + 统计
./run.command snapshot --label 10-22 --counts data/counts/counts_2026-10-22.json
./run.command report
```

## 4. 每天更新

```bash
./run.command fetch --label 10-23
./run.command snapshot --label 10-23 --counts data/counts/counts_2026-10-23.json
./run.command report
```

## 5. 命令速查

| 命令 | 作用 |
|---|---|
| `./run.command doctor` | 检查依赖、文件、Chrome 登录/页面脚本 |
| `./run.command init` | 设置本人条件 |
| `./run.command download` | 下载官方资料 |
| `./run.command build` | 生成筛选工作簿 |
| `./run.command fetch --label 10-23` | 抓取报名人数 |
| `./run.command snapshot --label 10-23 --counts <json>` | 合并到 Excel |
| `./run.command report` | 生成统计表 |
| `./run.command all --label 10-24` | 抓取→合并→统计 |
| `./run.command guide` | 使用说明 |
| `./run.command` | 交互菜单 |

## 6. 输出位置

- 官方资料：`2027国考资料/01_招考公告与考试大纲/`、`02_政策法规/`、`03_常见问题/`、`04_相关下载/`、`05_岗位表/`（个人分包下为 `个人使用/2027国考资料/`）
- 筛选工作簿：`2027国考资料/06_个人筛选/...按本人条件筛选.xls`
- 统计表：`2027国考资料/06_个人筛选/2027国考_符合条件岗位_报名人数统计.xls`
- 抓取原始数据：`data/counts/counts_YYYY-MM-DD.json`
