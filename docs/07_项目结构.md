## 数据流

```
download → 2027国考资料/05_岗位表/*.xls
   ↓
init → gk2027_config.json（本人条件）
   ↓
build → 06_个人筛选/...筛选.xls（颜色 + 符合条件岗位 + 地区表）
   ↓
fetch → data/counts/counts_日期.json
   ↓
snapshot → 在筛选.xls 右侧追加一天的报名人数/报录比/较昨日增加
   ↓
report → 2027国考_符合条件岗位_报名人数统计.xls（总表 + 汇总 + 说明）
```

## 模块职责

| 模块 | 职责 |
|---|---|
| `matcher.py` | 学历/学位/政治面貌/专业/年龄/应届/英语/户籍/证书等规则 |
| `downloader.py` | 专题网站文章、附件、岗位表下载 |
| `excel_build.py` | 生成带颜色/新 sheet 的工作簿 |
| `fetch.py` | Chrome 登录态下抓取报名人数 |
| `excel_snapshot.py` | 把某天 counts 合并进工作簿 |
| `stats_report.py` | 生成统计表 |
| `cli.py` | argparse + 交互菜单 + init 向导 |
| `util.py` | 配置、路径、AppleScript/Chrome |

## Git 忽略

- `.venv/`、`__pycache__/`、`.DS_Store`
- `gk2027_config.json`（个人条件）、`考生基本信息.png`
- `个人使用/`、`2027国考资料/`、`data/`（可重新 download/fetch）
- 根目录旧数据文件（`*.xls`、`*.zip`、`*.doc`、`*.pdf`、`*.png`）
